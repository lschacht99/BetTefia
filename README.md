# Beth Tephilah Synagogue website

This repository now contains a focused static website for Beth Tephilah Synagogue in Troy, NY. Irrelevant Hamsa Nomads/video-generation app files were removed so the repo is dedicated to the shul website.

## Site

- Root `index.html` redirects to `bet-tefila-troy/index.html`.
- Main site files live in `bet-tefila-troy/`.
- The website includes history, 360° sanctuary tour links, event calendar/planning, donation interest forms, contact forms, and nearby-stay/traveler logistics.

## Local preview

Open `index.html` or run a static server from the repo root, for example:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/`.
